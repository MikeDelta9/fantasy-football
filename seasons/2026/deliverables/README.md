# Deliverables

Anything league members read: rule-change announcements, the league constitution,
season recaps, draft-day handouts.

Two things follow from having an audience:

- **Say what changed and why.** A scoring rule that silently didn't survive the move
  from Sleeper reads as a commissioner error the first time someone notices.
- **Date them.** "The scoring we agreed" is a claim about a moment in time.
