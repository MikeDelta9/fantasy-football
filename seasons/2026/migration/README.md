The work record for the one-time move. The *runbook* is `docs/league-migration.md`;
this folder holds what actually happened.

Expected contents:

- `change-list.md` — generated by `ff diff --out`, the thing you work from
- `applied-<date>.md` — what you actually changed, when the change-list and reality
  diverged, and why
- `non-scoring-checklist.md` — rosters, waivers, playoffs, keepers: the settings the
  diff doesn't cover

Every unportable scoring rule resolved here gets a row in `_project/DECISIONS.md`.
Status goes in `../SEASON_INDEX.md`, not here.
